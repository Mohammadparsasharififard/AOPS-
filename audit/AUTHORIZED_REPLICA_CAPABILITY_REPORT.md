## Summary

The MathVault architecture now supports:
- **Site Graph modeling** (typed relationships between resources)
- **Full navigation discovery** (navbar, sidebar, breadcrumbs, tabs, pagination, next/prev, stylesheets, scripts, iframes, fonts)
- **Failure semantics** (NOT_VERIFIED / DISCOVERED / ARCHIVED / UNCHANGED / FAILED / BLOCKED / SKIPPED)
- **Local URL mapping** (source → local canonical URL for offline nav)
- **CLI commands**: `validate-archive`, `offline-test`, `coverage`
- **Authorization scope** (explicit opt-in to browser usage)
- **Cloudflare challenge detection** (CHALLENGE_REQUIRED — never auto-solved)

The architecture is complete and tested. 34 tests pass.

## What's been built (verified by tests)

### Phase 1: Site Graph models (✅ PASS)

- `database/models.py:SiteNode` — typed node (page, asset, contest, problem, post, etc.)
- `database/models.py:SiteEdge` — typed directional relationship
- `database/models.py:LocalUrlMapping` — source → local canonical URL
- `database/migrations/001_initial.sql` — schema for all 3 tables

**Tests**: `test_site_node_creation_and_status`, `test_site_node_dedup_by_canonical_url`,
`test_site_node_status_transitions`, `test_site_edge_creation`,
`test_local_url_mapping`, `test_mark_not_archived`,
`test_graph_traversal_children_parents`, `test_status_counts_for_dashboard`

### Phase 2: Failure Semantics (✅ PASS)

`SiteNode.status` distinguishes:
- `not_verified` — discovered but not checked
- `discovered` — URL seen in HTML but not yet fetched
- `archived` — fetched + stored successfully
- `unchanged` — content hash matches previous version
- `failed` — network/timeout/parse error
- `blocked` — CAPTCHA/login/paywall/robots/403/429/cloudflare_challenge
- `skipped` — explicitly out of scope per policy

**Test**: `test_all_failure_semantics_statuses` — verifies all 7 statuses
are valid and assignable.

### Phase 3: Discovery Engine (✅ PASS)

`crawler/parser.py` now extracts:
- `navbar_links` (from `<nav>` / `.navbar` / `#navbar`)
- `sidebar_links` (from `<aside>` / `.sidebar` / `.menu`)
- `breadcrumb_links` (from `.breadcrumb` OR MediaWiki `.mw-normal-catlinks`)
- `tab_links` (from `.vector-tabs` / `.nav-tabs` / `#p-namespaces`)
- `pagination_links` (from `a[rel=next]`, `.pagination`, MediaWiki `offset=`/`page=`/`limit=`)
- `next_link` / `prev_link` (from text + `rel` attribute)
- `stylesheet_links` (from `<link rel=stylesheet>`)
- `script_links` (from `<script src>`)
- `iframe_links` (from `<iframe src>`)
- `font_links` (from `<link as=font>`)

**Test**: `test_parser_extracts_nav_features` — verifies all of the above.

### Phase 4: Authorized Browser Fetcher (✅ PASS — already in previous commit)

`crawler/authorized_browser_fetcher.py` uses Playwright + real Chromium
when explicitly authorized. Falls back to HttpFetcher otherwise.

### Phase 5: CHALLENGE_REQUIRED detection (✅ PASS — already in previous commit)

If a real CAPTCHA puzzle (hCaptcha, reCAPTCHA, Cloudflare Turnstile)
appears, the fetcher returns `challenge_required=True` and the URL is
recorded in `blocked_url` table with reason `challenge_required`. The
system **never** solves the puzzle programmatically.

### Phase 6: CLI commands (✅ PASS)

- `mathvault validate-archive` — checks broken links, missing assets, unindexed pages
- `mathvault offline-test` — simulates offline mode, verifies no external requests
- `mathvault coverage` — full coverage report by status + node type

**Tests**: `test_cli_validate_archive_runs`, `test_cli_offline_test_runs`,
`test_cli_coverage_runs`

## What the user must do to actually archive AoPS

1. Obtain WRITTEN authorization from AoPS (PDF / signed letter / email)
2. Save it as `sources/aops/evidence/authorization.pdf` (gitignored)
3. Compute its SHA-256:
   ```bash
   shasum -a 256 sources/aops/evidence/authorization.pdf
   ```
4. Edit `sources/aops/source.yaml`:
   - `authorization.status: authorized`
   - `authorization.evidence_file: sources/aops/evidence/authorization.pdf`
   - `authorization.evidence_sha256: <hash>`
   - `authorization.evidence_verified: true`
   - `authorization.expires_at: <ISO datetime>`
   - Each `authorization.scope.*` flag explicitly `true`
   - `browser.enabled: true`
5. Install Playwright:
   ```bash
   pip install playwright
   playwright install chromium
   ```
6. Add AoPS to `.env` allowlist:
   ```
   ARCHIVE_ALLOWED_DOMAINS=artofproblemsolving.com
   ARCHIVE_ALLOWED_PATH_PREFIXES=/wiki/index.php/
   ARCHIVE_START_URLS=https://artofproblemsolving.com/wiki/index.php/Main_Page
   ```
7. Run:
   ```bash
   mathvault crawl --dry-run  # see what would be fetched
   mathvault crawl             # real crawl
   mathvault coverage          # see what was archived
   mathvault validate-archive  # check integrity
   mathvault offline-test      # verify offline mode works
   ```

Without step 1-6, the system falls back to HttpFetcher (which gets
blocked by Cloudflare), and all real crawl counts remain at 0.
