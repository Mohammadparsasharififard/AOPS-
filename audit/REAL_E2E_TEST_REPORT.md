## What the user must do for production

1. **Replace the TEST evidence file** with a real authorization document
   from AoPS:
   ```bash
   # Save the real authorization document
   cp /path/to/aops_authorization.pdf sources/aops/evidence/authorization.pdf
   # Compute SHA-256
   shasum -a 256 sources/aops/evidence/authorization.pdf
   # Edit sources/aops/source.yaml:
   #   evidence_file: sources/aops/evidence/authorization.pdf
   #   evidence_sha256: <new hash>
   ```

2. **For URLs that return real CAPTCHAs** (like IMO Problems), set
   `browser.headless: false` so a human can solve the CAPTCHA once:
   ```yaml
   browser:
     headless: false  # set to true after first run if cf_clearance persists
   ```

3. **Scale up the crawl**: increase `CRAWL_MAX_PAGES` and
   `CRAWL_MAX_DEPTH` to archive more pages.

4. **Run incremental syncs**: `mathvault sync` will only re-fetch
   pages that changed (using ETag + content hash).
